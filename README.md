# LANLdocs

This repository has been unmaintained since 2019. The last commit before this notice was on 22 July 2019. It holds unofficial copies of Los Alamos National Laboratory accelerator-code manuals. It is not an official LANL distribution.

The Poisson Superfish documentation (LA-UR-96-1834) prints: "Copyright, 1985-2006, The Regents of the University of California." It states that the work was produced under U.S. Government contract W-7405-ENG-36 by Los Alamos National Laboratory, operated by the University of California for the U.S. Department of Energy. Parmela (LA-UR-96-1835) prints the same form of notice for 1985-2005.

## Credentials removed from the current tree

These files printed retired Los Alamos Accelerator Code Group (LAACG) FTP usernames and passwords, and they have been deleted from the current tree:

- `SFINTRO.DOC`
- `SFINTRO.pdf`
- `TRACE3Dpac97.pdf`

`LANLHELP.dic` and `LANLHELP.DOT` were Word spellcheck files. The dictionary contains personal email addresses, so both files have been deleted from the current tree.

The LAACG FTP servers described in these manuals are retired. Copies of the deleted files remain in the git history of this repository.
